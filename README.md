# 111电气梅努斯智能车 · TC264 测试工程合集

福州大学梅努斯国际工程学院 · 电气工程及其自动化 —— 智能车项目的各个分模块测试工程。

主控为 **英飞凌 TC264D**（AURIX™），开发环境 **AURIX Development Studio 1.10.40**，底层库为 **逐飞科技 TC264 开源库**，
主控板型号 **TC264 主控板 V1.2**。

每个子目录都是一个**独立的 ADS 工程**（含 `.cproject` / `.project` / `.settings`），可以单独导入、单独编译烧录，
互不影响。

---

## 工程一览

| 目录 | 内容 | 说明 |
|---|---|---|
| [`camera`](camera) | 摄像头图像采集与显示 | MT9V034 采集图像 → 2 寸 IPS200 显示；按键 1/2 调曝光、按键 3 切灰度/二值、按键 4 调阈值；串口打印均值与耗时 |
| [`drive_test`](drive_test) | **硬件驱动自测（推荐先跑这个）** | "插什么测什么"：LED / 按键 / 屏幕 / 串口 / 电机 / 舵机 / 编码器 / 拨码 / 陀螺仪 / 摄像头 / 测距 / Flash / 一键全部自检 |
| [`imu`](imu) | IMU660RA 姿态解算 + 里程定位 | 互补滤波算 pitch/roll/yaw、陀螺零漂校准并存片内 Flash、双路编码器里程计、航迹推算坐标、轨迹小地图、航点记录；在 `menu` 工程上扩展 |
| [`keytest`](keytest) | 按键引脚定位测试 | 读 12 个候选引脚电平，按哪个键哪一行变红 —— 用来确认每个按键真正接在 TC264 的哪个脚 |
| [`menu`](menu) | 四级多级菜单 + 参数掉电保存 | 主菜单 3 项、3 组共 12 个参数、修改/保存弹窗确认、片内 DFlash 双页备份掉电保存、按键自检页 |
| [`patrol`](patrol) | 循迹图像识别 | 摄像头图像二值化 → 边线提取 → 中线偏差与赛道状态求解，算法在 `car_image.c`，屏幕上叠加画出边线与中线 |
| [`screen`](screen) | 屏幕点亮验证 | 最简工程：CPU1 上 `ips200_init()` 后显示一行文字，用来确认屏幕排线、供电、SPI 是否正常 |
| [`servo_bds300`](servo_bds300) | **BDS300 舵机 + 菜单标定（最新）** | 4 键菜单改参数**退出即生效、自动存 Flash**（不用再找"保存"那一行）；角度 ⇄ 脉宽双向联动；三点标定 `1040/1540/2040 µs` ↔ `0/90/180°`，为机械装不正做了 40 µs 中位补偿（斜率不变）；IPS200 只重画变动行 + SPI 30 MHz；附 Python 虚拟舵机联调工具（没接硬件也能看输出） |
| [`servo_test`](servo_test) | 舵机 PWM 输出测试 | 上电即在 `P33.9`、`P21.6` 两路输出 50 Hz / 1500 µs 标准舵机信号，无按键无串口 |

## 快速开始

### 导入工程

1. 打开 **AURIX Development Studio**（1.10.40）
2. `File → Import → General → Existing Projects into Workspace`
3. `Select root directory` 选到**某个子目录**（例如 `menu`），Finish
4. 若 Project Explorer 里看不到新文件：右键工程 → `Refresh`（F5）
5. `Project → Clean` 然后 `Project → Build Project`（**Debug 配置**）
6. 接上下载器 → `Debug` 下载（第一次会停在 `core0_main`，按 F8 继续）
7. 重新烧录前，先把上一次的调试会话 **Terminate** 掉（ADS 同时只允许一个调试会话）

> Debug 编译产物（`Debug/` 目录）、`.launch` 调试配置都**没有上传**，克隆后第一次 Build 会自动生成。

### 通用硬件约定

| 外设 | 接口 | TC264 引脚 |
|---|---|---|
| 2 寸 IPS200 屏幕 | SPI2 | SCK `P15_3` / MOSI `P15_5` / CS `P15_2` / RST `P15_1` / DC `P15_0` / BLK `P15_4` |
| 4 个按键 | — | 1 上选 `P20_6` / 2 下选 `P20_7` / 3 确定 `P11_2` / 4 返回 `P11_3` |
| 调试串口 | UART | TX `P14_0` / RX `P14_1`，115200 8N1 |
| 摄像头 MT9V034 | 并口 + SCCB | D0~D7 `P00_0~P00_7`，VSY `P02_0`，PCLK `P02_1`，TXD `P02_3`，RXD `P02_2` |
| IMU660RA | SPI0 | SCL `P20_11` / SDA `P20_14` / SDO `P20_12` / CS `P20_13` |
| 编码器 1 / 2 | TIM4 / TIM5 | `P02_8`+`P00_9` / `P10_3`+`P10_1` |

⚠️ **屏幕和 IMU 模块的 VCC 必须接 3.3 V**，接 5 V 会烧。只插下载器不给主板供电时，5 V 轨只有 3.1 V，屏幕可能全黑。

详细接线、按键操作、参数标定方法、常见问题，各工程的说明文档里都有：

- `menu/README_菜单工程说明.md`
- `servo_bds300/README_菜单工程说明.md`（舵机标定与菜单操作，最新版）
- `imu/使用说明.md`
- `keytest/README_按键测试.md`
- `drive_test/驱动自测使用说明.txt`（GBK 编码）
- `camera`、`patrol`、`servo_test` 的功能说明写在各自 `user/cpu0_main.c` 的文件头注释里

## 协作

多人一起开发请看 **[CONTRIBUTING.md](CONTRIBUTING.md)** —— 环境版本、git 身份配置、**编辑器必须设 GBK 编码**、一人一目录的分工约定、提交与冲突处理都在里面。

## 关于源码编码

所有工程源码是 **GBK（GB2312）编码**（Keil / ADS 在中文 Windows 下的默认编码）。

- 在 ADS、Keil、VSCode（设 `files.encoding: gbk`）里打开显示正常
- **GitHub 网页上直接预览 `.c/.h` 时中文注释会显示乱码**，这是编码显示问题，不影响代码本身
- 如果想在网页上看中文，本地用命令转 UTF-8 再看，不要直接改文件编码后提交（改错编码会导致编译器把中文注释当非法字符报错）
