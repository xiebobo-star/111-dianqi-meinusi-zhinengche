# 循迹程序模块说明

本次把原来集中在 `car_control.c` 中的圆环和普通弯道逻辑拆成独立的 `.c/.h` 模块，仍放在 `user` 目录。现有识别算法、参数值、启动条件和故障停车条件保持不变。

| 模块 | 文件 | 负责的工作 |
|---|---|---|
| 圆环 | `user/car_ring.c/.h` | 入环方向提示、入环、环内绕行、出环、圈完成标志、IMU 转角累计、圆环限速和超时检查 |
| 普通直道与弯道 | `user/car_turn.c/.h` | 根据中线偏差调用转向 PD，按横向偏差与前方弯曲减速，根据实际舵角分配左右轮速度 |
| 总调度与停车 | `user/car_control.c/.h` | 连续帧检查、启停、处理圆环检查结果、目标渐变、速度 PI 调用、编码器异常和堵转保护 |
| 图像识别 | `user/car_image.c/.h` | 阈值分割、路面边缘与中线搜索、历史路宽、岔路歧义及指定方向的支路提取 |
| PID 计算 | `user/car_pid.c/.h` | 转向 PD、速度 PI、滤波与抗积分饱和 |
| 硬件适配 | `user/car_board.c/.h` | IMU 初始化/采样、编码器读取、PWM 输出和共享状态保护 |
| 主循环与中断 | `user/cpu0_main.c`、`user/isr.c` | 图像快照、显示、按键和定时中断入口 |

## 普通拐弯怎么处理

`car_turn_plan()` 使用图像的 `err_norm` 和 `bend_norm` 计算目标舵机脉宽与平均目标速度。左弯、右弯共用同一公式，由偏差符号决定方向；偏差小、前方平直时使用直道速度，偏差或弯曲程度增大时减速。置信度低或远处有效行不足时进一步限速。

`car_turn_wheel_targets()` 根据经过限幅、渐变后的实际舵机脉宽分配轮速，右转时左轮更快，左转时右轮更快。该函数在 10 ms 调度中调用。

这次封装的是已有的普通中线循迹拐弯逻辑，没有新增直角弯、掉头或其他特殊赛道元素的识别策略。

## 圆环怎么处理

`car_ring` 单独保存圆环状态，控制器通过 `c->ring` 持有它。圆环模块不依赖 `car_control.h`，不直接操作硬件，也不自行改变整车停车状态。

1. `CAR_RING_APPROACH`：连续观察普通路面的弯向；遇到岔口后，按配置或可靠提示选择入环方向。
2. `CAR_RING_ENTER`：请求图像模块沿入环方向选支；连续恢复清晰路面且累计转角达到 30 度后进入环内。
3. `CAR_RING_INSIDE`：普通中线循迹，继续累计 IMU 转角；达到配置的转角区间并再次看到岔口后进入出环阶段。
4. `CAR_RING_EXIT`：请求与入环相反的选支方向；连续恢复清晰路面且出环持续至少 200 ms 后标记完成。
5. `CAR_RING_DONE`：取消圆环选支和圆环限速；再次启动时重新开始流程。

`car_ring_motion()` 更新 IMU 时效和转角；`car_ring_vision()` 推进阶段，在入环/出环转换时通知调度层清除转向微分历史；`car_ring_check()` 返回 IMU 或圆环限制异常，由调度层统一停车。连续无效帧、未解决岔路的停车检查仍在调度层执行。

## 调用顺序

主循环先按 `car_control_route()` 返回的方向设置图像选支，然后识别当前快照，调用 `car_control_vision()`。调度层依次更新圆环阶段、检查图像是否可用、调用弯道转向和速度规划，再应用圆环限速。

10 ms 中断先通过 `car_control_motion()` 提交 IMU 数据，然后调用 `car_control_tick()`：检查故障、平滑目标、分配左右轮速度、计算速度 PI，最后由硬件层写入 PWM。

## 修改与构建

调普通拐弯算法看 `car_turn.c`，调圆环阶段条件看 `car_ring.c`，调 PID 公式看 `car_pid.c`；所有原有可调参数继续集中在 `car_config.h`。

ADS 工程的源码目录配置包含 `user`，新增两个 `.c` 文件放在该目录下。打开本目录对应的工程后先执行 **Refresh**，再执行 **Build**，确认编译输出包含 `car_ring.c` 和 `car_turn.c`。不要直接沿用当前 `Debug` 下的旧 makefile：它是自动生成文件，仍带有旧工程绝对路径和旧源码列表。本次没有手工改写这些生成文件，也没有重新生成板端 ELF/HEX。

主机验证命令：`python tests/run_host_tests.py --output <工程目录外的临时目录>`，需要 GCC。现有集成测试保留原断言，仅更新圆环结构字段路径；新增模块测试只链接圆环、弯道和 PID，验证它们可以脱离总调度和硬件层独立使用。

本次通过主机编译和测试；未执行 ADS/TASKING 板端构建、烧录或实车试跑。`BUILD_VERIFICATION.md` 中的板端验证记录属于拆分前的历史版本。
