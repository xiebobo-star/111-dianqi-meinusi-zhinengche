# car_run · TC264 循迹跑车

**能真正跑起来的那个工程**：白色路面识别 → 转向 PD + 速度 PI 闭环 → 左右轮差速 + 舵机，带圆环状态机、IMU 只用来数环内转角、一整套故障停车保护，外面套一层菜单（屏幕 / 4 键 / 参数掉电保存 / 状态页 / 自检）。

- 识别与控制算法来自队友的 `patrol` 工程（白路面 / 蓝底适配、圆环、PD/PI、安全停车，带主机测试），**算法本身一行没改**
- 菜单 / 参数框架、屏幕封装、按键扫描、Flash 掉电保存来自本仓库的 `menu` / `smartcar`
- 新增：运行期参数桥 `car_tune`（菜单里改完立刻生效）、编码器模块 `enc_pd1503`（PD-1503，真实单位）

> 只想要「每个模块单独测」的那个工程，去看 [`smartcar`](../smartcar)；这个是「跑车」的那一份。

- 主控 **英飞凌 TC264D**，AURIX Development Studio 1.10.40，逐飞 TC264 开源库，主板 TC264 V1.2
- 屏幕默认 **1.8 寸 TFT180（128×160）**；换成 IPS200 就把 `car_config.h` 的 `CAR_USE_IPS200` 改成 1
- 赛道：**蓝色底 + 白色宽路面**（识别靠亮度差，不认色相）

## 3. 参数表（5 组 29 项，改完立刻生效 + 掉电保存）

| 组 | 参数 | 说明 |
|---|---|---|
| 舵机参数 | 中位us / 左限us / 右限us / 转向Kp / 转向Kd / 差速% | 中位默认 1540 µs（BDS300 装车后必须标）；差速默认 0.15 = 弯道外轮快 15% |
| 速度参数 | 直道速 / 弯道速 / 谨慎速 / 速度Kp / 速度Ki / PWM上限 / 每圈脉冲 / 轮径 | 速度用 **mm/s**；PI 内部单位是「脉冲/10ms」，靠「每圈脉冲 + 轮径」换算 |
| 摄像头参数 | 曝光 / 二值阈 / 显示 | 阈值 0 = 自动大津法；显示 0 灰度 1 二值 |
| 圆环参数 | 圆环 / 入环向 / 环速度 / 环超时 | 入环向 0 自动（靠弯向提示）/-1 左/+1 右；关掉圆环就只当普通弯道跑 |
| 系统参数 | LED / 串口 / 上电延时 / 电机L反 / 电机R反 / 编码L反 / 编码R反 / 编码模式 | 编码模式 0 = 脉冲+方向，1 = 正交AB |

参数存片内 DFlash 第 10/11 页（双页备份）。参数项数一变，老 Flash 记录自动作废 → 改完参数表第一次上电一定是默认值。

## 4. 硬件接线

| 外设 | 接口 | TC264 引脚 |
|---|---|---|
| TFT180 屏幕 | SPI2 | SCK `P15_3` / MOSI `P15_5` / CS `P15_2` / RST `P15_1` / DC `P15_0` / BLK `P15_4` |
| 4 个按键 | — | 1 `P20_6` / 2 `P20_7` / 3 `P11_2` / 4 `P11_3` |
| 摄像头 MT9V034 | 并口 + SCCB | D0~D7 `P00_0~P00_7`，VSY `P02_0`，PCLK `P02_1`，TXD `P02_3`，RXD `P02_2`，**VCC 3.3 V** |
| 电机 左 / 右 | PWM + DIR | `P21_2`+`P21_3` / `P21_4`+`P21_5`，17 kHz |
| 舵机 BDS300 | PWM 50 Hz | `P33_9` |
| 编码器 1 / 2 | TIM4 / TIM5 | A `P02_8` B `P00_9` / A `P10_3` B `P10_1` |
| IMU660RA | SPI0 | `P20_11` / `P20_14` / `P20_12` / `P20_13`（只用于圆环转角） |
| 调试串口 | UART0 | TX `P14_0` / RX `P14_1`，115200 |
| 核心板 LED | — | `P20_9` / `P20_8` |

**PD-1503 编码器两种接法**（菜单「编码模式」切换，不用改代码）：

| 型号 | 线 | 接法 | 菜单 |
|---|---|---|---|
| PD-1503-SDI（脉冲 + 方向，「1024 线带方向」那种） | A、B/DIR、VCC、GND | A→`P02_8`(或 `P10_3`)，DIR→`P00_9`(或 `P10_1`) | 编码模式 = 0 |
| PD-1503-ENC（正交 AB） | A、B、VCC、GND | A→`P02_8`，B→`P00_9` | 编码模式 = 1 |

⚠️ 编码器 **VCC 按型号接 3.3 V 或 5 V，GND 一定要和主板共地**；线序接反不烧，但读数会反向 → 用「编码L反 / 编码R反」参数纠正。
⚠️ 屏幕、摄像头 VCC 必须 3.3 V；只插下载器不接电池时 5 V 轨只有 3.1 V，屏可能全黑。

## 5. 编码器（PD-1503）标定：先做这一步，后面所有速度才有意义

菜单里只需要填 **两个数**，速度和里程就都是真实单位了（不用管齿轮比、不用数倍频）：

1. 把车架起来，进「系统信息 → 硬件自检」（或跑车页），屏幕上能看到 `编码总 L xxx R xxx`
2. 长按按键3 把总脉冲清零；
3. **手推车轮正好转一圈**，记下 `L`（或 `R`）的总脉冲数；
4. 进「参数设置 → 速度参数 → 每圈脉冲」，把这个数填进去（两个轮子传动比一致时用同一个值）；
5. 量一下车轮直径，填进「轮径」（默认 61.0 mm）。

判读：

| 现象 | 结论 |
|---|---|
| 往前推，总脉冲是**负数** | 方向反了 → 打开「编码L反 / 编码R反」 |
| 转一圈读数 ≈ 1024（或 2048 / 4096） | 正常，说明是 1024 线编码器（正交接法会是 4 倍） |
| 转一圈读数忽大忽小 / 归零 | 线序或共地有问题，先查接线（读数异常大时固件会标记「编码异常」并停车） |
| 读数一直是 0 | 编码模式选错了（脉冲+方向 ↔ 正交），或者 VCC/GND 没接 |

## 6. 上板调试顺序

1. **只插屏幕 + 4 键**：主菜单出来 → 「系统信息 → 按键自检」确认 4 个键都认
2. **摄像头**：「摄像头调试」页把车放到赛道上，1/2 调曝光，让白路面亮、蓝底暗；3 键切二值图确认分割干净；长按3 冻结看细节
3. **编码器**：按第 5 节标定「每圈脉冲」，确认前进时读数为正（负数就开取反）
4. **舵机**：停止状态下把「舵机参数 → 中位us」调到车正前方；再调左/右限（默认 1340 / 1740 µs，别超过舵机机械行程）
5. **电机**：车轮架空，进跑车页按 3 启动 —— 会先要求 3 帧有效图像；确认两个轮子都往前转（不转/反转改「电机L反 / 电机R反」）
6. **速度环**：先只调「速度Kp」（「速度Ki」临时设 0），让实际速度跟得上目标、不振荡；再加一点 Ki 消掉稳态误差
7. **转向 PD**：低速跑直道，`转向Kp` 从 150 起调，车能跟着弯道走；加少量 `转向Kd`（6 起）压掉摆头
8. **差速**：直道正常后再开「差速%」(0.15 起)，让弯道外轮快一点
9. **圆环**：先把「入环向」设成固定方向（-1 / +1）验证入环-绕行-出环，再改成 0 自动；`环速度` 起步给低一点
10. 全都顺了再逐步加「直道速 / 弯道速」

串口（115200）会打启动信息：屏幕型号、参数项数、舵机中位、直道速度、每圈脉冲、轮径、圆环开关。

## 7. 安全机制（都在 `car_control.c` / `car_board.c` 里）

- **上电第一步就把车按住**：`car_board_motor_safe()` 紧跟 `clock_init()` 执行 —— 两个 EN（`P21_2`/`P21_4`）推挽拉低、两个 DIR 给确定电平、PWM 0%，都在屏幕初始化（几百 ms）之前完成。P21_2~P21_5 复位后是输入态，驱动板 EN 的上拉会让电机全速转，这一步不放在最前面就会「上电飞车」
- 上电停车；只有跑车页按 3 才启动，且启动要 **连续 3 帧有效图像**（无岔路歧义）+ 圆环需要的 IMU 已就绪
- 运行中任何一条成立就**撤销动力并锁存停车**（要重新按 3 才再启动）：
  连续 3 帧丢线 / 连续 3 帧岔路歧义 / 超过 150 ms 没有新图 / 编码器读数反向或异常大 / 某侧 PWM 达到 700 但速度长期 < 1（堵转，500 ms）/ 圆环超时或转角越界 / IMU 掉线
- **按键4 在 10 ms 中断里直接读**，屏在刷的时候也能停
- 停车只是 PWM 归零（滑行），没有反向制动；所以赛道尽头别指望它自己刹住
- 硬件上建议再加一道保险：在驱动板 EN 与 GND 之间并 10 kΩ 下拉电阻，这样即使 MCU 还没启动、引脚悬空，电机也不会转
