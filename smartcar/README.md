# smartcar · TC264 智能车合并工程

把仓库里 **12 个分模块测试工程合并成的一个工程**：一个 `.cproject`、一套参数表、一个菜单，
主菜单里进对应页面就能单独测那个模块，参数全部掉电保存。

主控 **英飞凌 TC264D**（AURIX™），开发环境 **AURIX Development Studio 1.10.40**，
底层库 **逐飞科技 TC264 开源库**，主控板 **TC264 主控板 V1.2**，屏幕 **1.8 寸 TFT180（128×160）**。

> 想单独研究某个模块的原始工程，还是去对应的子目录看（`camera` / `imu` / `patrol` …），
> 这个 `smartcar` 是它们的合集，改代码请改这一份，别再分头改。

## 1. 主菜单

```
主菜单
 ├─ 摄像头循迹 ─ 图像显示 / 循迹识别
 ├─ 姿态定位 ─ 姿态显示 / 陀螺校准 / 里程定位 / 航点记录
 ├─ 测距模块 ─ 实时测距 / 测距统计
 ├─ 电机编码器 ─ 电机输出 / 编码器
 ├─ 舵机标定 ─ 直接进「舵机参数」那一组（脉宽 / 角度 / 三点标定）
 ├─ 参数设置 ─ 电机 / 舵机 / 摄像头 / 测距 / 系统参数 + 恢复全部默认
 ├─ 状态查看 ─ 运行状态 / 存储状态 / 参数总览
 └─ 系统信息 ─ 版本信息 / 硬件信息 / 操作说明 / 按键自检 / 硬件自检
```

TFT180 一屏 7 行，主菜单 8 项：光标走到底部时列表**自动向上滚动**，不需要手动翻页。

## 2. 按键

四个键固定分工，和板子丝印一一对应：

| 键 | 引脚 | 菜单里 | 参数编辑时 | 各功能页 |
|---|---|---|---|---|
| 按键1 | `P20_6` | 上选 | 加一档（按住连发，长按 ×10 大步） | 摄像头：曝光 +  电机：占空比 +  陀螺：上一页 |
| 按键2 | `P20_7` | 下选 | 减一档 | 摄像头：曝光 −  电机：占空比 − |
| 按键3 | `P11_2` | 确定 / 进入 | 完成（退出修改，立刻存 Flash） | 图像页灰度↔二值 / 循迹页阈值 +10 / 电机选轮 / 编码器清零 / 陀螺校准 |
| 按键4 | `P11_3` | 返回上一层 | 完成 | 退出该页回菜单 |

**长按按键4 = 任何页面直接回主菜单。长按按键3 = 摄像头页冻结 / 恢复画面**（调曝光、阈值时把画面定住看）。
参数改完不用找「保存」：退出修改界面立刻写 Flash；停手 0.8 s 也会自动写一次。

## 3. 参数表（5 组 21 项，掉电保存）

| 组 | 项 | 说明 |
|---|---|---|
| 电机参数 | 测试占空比 / 左轮取反 / 右轮取反 | 电机页的占空比（0~10000），轮子反转就开取反 |
| 舵机参数 | 脉宽us / 角度 / Pulse min / Pulse cen / Pulse max / Pulse en | 脉宽是唯一真值，角度是换算显示；三点标定做中位补偿 |
| 摄像头参数 | 曝光 / 二值阈值 / 循迹显示 | 阈值 0 = 自动大津法，非 0 = 手动；循迹显示 0 灰度 1 二值 |
| 测距参数 | 报警距离 / 零点偏移 / 滤波等级 / 单位cm / 报警开关 | 测距页和报警逻辑读它 |
| 系统参数 | LED指示 / 串口调试 / 上电延时 / 轮径 | 轮径填进去里程计直接按它换算（0.1 mm 精度） |

存片内 DFlash：菜单参数用第 **10 / 11 页**（双页备份），陀螺零漂 + 航点用第 **8 / 9 页**，互不影响。
参数项数变了以后老 Flash 数据整页作废，所以改参数表后第一次上电一定是默认值。

## 4. 硬件接线

| 外设 | 接口 | TC264 引脚 |
|---|---|---|
| TFT180 屏幕 | SPI2 | SCK `P15_3` / MOSI `P15_5` / CS `P15_2` / RST `P15_1` / DC `P15_0` / BLK `P15_4` |
| 4 个按键 | — | 1 上选 `P20_6` / 2 下选 `P20_7` / 3 确定 `P11_2` / 4 返回 `P11_3` |
| 摄像头 MT9V034 | 并口 + SCCB | D0~D7 `P00_0~P00_7`，VSY `P02_0`，PCLK `P02_1`，TXD `P02_3`，RXD `P02_2`，**VCC 3.3 V** |
| IMU660RA | SPI0 | SCL `P20_11` / MOSI `P20_14` / MISO `P20_12` / CS `P20_13` |
| 编码器 1 / 2 | TIM4 / TIM5 | A `P02_8` B `P00_9` / A `P10_3` B `P10_1` |
| 电机（左 / 右） | GTM PWM + DIR | `P21_2`+`P21_3` / `P21_4`+`P21_5`，17 kHz |
| 舵机 | GTM PWM 50 Hz | `P33_9`（主板舵机口信号） |
| TOF 测距（VL53LXX） | 软 IIC | SCL `P33_4` / SDA `P33_5` / XSHUT `P20_10`，**VIN 5 V** |
| 调试串口 | UART0 | TX `P14_0` / RX `P14_1`，115200 8N1 |
| 核心板 LED | — | LED1 `P20_9` / LED2 `P20_8`（`P21_4`/`P21_5` 被电机信号占了，不能当灯用） |

⚠️ 屏幕、IMU、摄像头的 VCC **必须 3.3 V**（接 5 V 会烧）；只插下载器不接电池时 5 V 轨只有 3.1 V，屏幕可能全黑。
⚠️ 舵机、电机都从电池取电，共地要接好；测电机前把车架起来，或者先关掉驱动板上的使能拨动开关。

## 5. 每个页面怎么用

### 摄像头循迹
- **图像显示**：原图 / 二值图 + 曝光 / 阈值 / 帧率 / 亮度均值。1/2 调曝光，3 切灰度↔二值。
- **循迹识别**：二值图 + 每行中线（绿 = 真找到，黄 = 补出来的，红 = 丢线，蓝虚线 = 图像中心），
  文字是偏差 `err` / 归一化偏差 `norm` / 状态 / 找到几行 / 阈值。3 键阈值 +10（加到 240 之后回自动）。
- **长按 3 = 冻结画面**：画面停在当前这一帧，方便慢慢看中线对不对、调阈值；再长按 3 恢复（行尾显示「已冻结」）。
- 文字区**只重画数值变了的那一行**，不再整块清屏，所以数值跳动不会有频闪；图像本身是按摄像头帧率刷新的实时预览。
- 算法全在 `car_image.c`（单线/双线、阈值、权重在 `car_image.h` 顶部改），屏上只负责画。
- 摄像头是**懒初始化**：第一次进这两页才 `mt9v03x_init()`，不进就不占 `P00`/`P02` 口。

### 姿态定位
- **姿态显示**：roll / pitch / yaw + 静止判断；**陀螺校准**：算零漂、存 Flash（长按 3）；
- **里程定位**：X / Y / 里程 + 轨迹小地图；**航点记录**：记录 / 删除 / 清空。
- 解算和里程计都在 10 ms 中断里跑（编码器 → 陀螺 → 里程计，顺序不能换）。

### 测距模块
- 实时测距页：大数字 + 量程条 + 曲线 + 阈值线；统计页：型号 / 帧率 / 最小最大平均 / 状态，3 键重试初始化。
- 初始化失败屏上直接显示型号原始值 + IIC 扫描结果，先查供电和 `XSHUT`。

### 电机编码器
- **电机输出**：3 键选「两轮 / 左轮 / 右轮」，1/2 加减占空比（10% 一档），同时显示两轮速度。
- **编码器**：本周期脉冲 / 速度 mm/s / 里程，3 键清零。
- 进页面占空比一律 0，退出页面先停机 —— 不会把上一次的 30% 留在轮子上。

### 舵机标定
进「舵机参数」组：改 `脉宽us`（唯一真值）舵机当场就动；`角度` 是换算值（改角度会反算脉宽）。
机构装不正就只调 `Pulse cen`（中位），三点间距保持 500 µs 则线性度不变。
`Pulse en` 关掉 = 不出波（量电平 / 拆舵机时用）。

### 系统信息
- **按键自检**：按哪个键，那一行变「按住」+ 每键累计次数。某个键次数一直 0 = 那个键/那根线的问题。
- **硬件自检**：进页面自动跑一遍 —— LED 闪 3 次、串口打一行、把参数写一遍 Flash 再回读校验。

## 6. 快速开始

1. 打开 **AURIX Development Studio 1.10.40**
2. `File → Import → General → Existing Projects into Workspace` → 选 **本目录 `smartcar`**
3. 右键工程 → `Refresh`（F5），`Project → Clean…` → `Project → Build Project`（**Debug 配置**）
4. 建调试配置：`Project → Debug As → Debug Configurations…`，Project 选 `smartcar`，
   C/C++ Application 指向 `Debug\smartcar.elf`；board 选你手上的调试器（`DAS JDS TriBoard …`）
5. 下载完第一次会停在 `core0_main`，按 **F8** 继续；重新烧录前先把上一次会话 **Terminate**

> 编译产物名跟着工程名走（`.cproject` 里 `artifactName = ${ProjName}`），所以是 `Debug\smartcar.elf`。
> 串口（115200）能看到启动信息：屏幕型号、参数项数、IMU / Flash / TOF / 舵机状态。

## 7. 上板验证顺序（一次插一样）

1. **只插屏幕 + 4 个按键**，上电：主菜单出来 → 进「系统信息 → 按键自检」按 4 个键
2. 进「系统信息 → 硬件自检」：看 LED 闪、串口有输出、Flash「存读通过」
3. → 「电机编码器 → 编码器」：手转轮子，脉冲数 / 速度跟着变（先确认编码器，再谈闭环）
4. → 「电机输出」：车轮架空，1 键加到 10~20%，两轮都往前转（反转就改「左/右轮取反」参数）
5. → 「舵机标定」：脉宽 1040 / 1540 / 2040 看舵机打三个点，机构不正就挪 `Pulse cen`
6. → 「姿态定位 → 姿态显示」：车放平，roll/pitch ≈ 0；转车 yaw 跟着变；再进「陀螺校准」
7. → 「测距模块」：手在车前 10~150 cm 来回，数字跟得上
8. → 「摄像头循迹」：图像页先调曝光（亮而不白），循迹页看中线贴不贴黑线

## 9. 常见问题

| 现象 | 先看这里 |
|---|---|
| 屏幕全黑 | 是不是只插了下载器没接电池（5 V 轨只有 3.1 V）；屏幕 VCC 是不是接了 5 V（要 3.3 V） |
| 某个键没反应 | 系统信息 → 按键自检，那一行次数一直是 0 就是键/线的问题，跟程序无关 |
| 摄像头显示 `摄像头未初始化` | 3.3 V 供电、TXD/RXD 是否交叉、D0~D7 排线方向；改完线按 4 返回再进（会重试初始化） |
| 测距页「未初始化」 | 模块 VIN 接 5 V、`XSHUT` 必须接 `P20_10`、SCL/SDA 是不是 `P33_4/P33_5` |
| 电机不动 | 驱动板使能拨动开关；万用表量 `P21_2`：0% 应 0 V、100% 应 3.3 V |
| **上电车自己冲出去** | 已修：上电第一步 `menu_motor_safe_init()` 就把 `P21_2`/`P21_4`（EN）推挽拉低、`P21_3`/`P21_5`（DIR）给确定电平、PWM 0%，在屏幕初始化之前完成。如果还动，就是驱动板 EN 上的上拉太强 → 在 EN 与 GND 之间加 10 kΩ 下拉，或者调试时先关掉板上的使能拨动开关 |
| 舵机不动 / 一直抖 | 舵机电源是不是从电池取（不要用 3.3 V 供舵机）；`Pulse en` 是不是关了 |
| 里程不准 | 系统参数里的「轮径」按实测量填（61.0 mm 只是默认值），编码器线数在 `imu_config.h` |

## 10. 源码编码

所有 `.c/.h` 是 **GBK（GB2312）**，ADS / Keil 里默认就对；VS Code 记得设 `files.encoding: gbk`。
GitHub 网页预览中文注释会乱码，这是编码显示问题，不要改成 UTF-8 再提交（编译器会把中文注释当非法字符）。

`user/` 下的文件：

| 文件 | 作用 |
|---|---|
| `menu_*` | 菜单框架：`menu_ui` 界面状态机、`menu_param` 参数表、`menu_flash` 掉电保存、`menu_display` 屏幕封装、`menu_font` 中文点阵（自动生成）、`menu_key` 按键扫描 |
| `menu_camera` / `menu_motor` / `menu_imu` / `menu_tof` | 各功能页面的画屏 + 按键 |
| `car_image` | 循迹识别算法（只算，不画屏） |
| `imu_attitude` / `imu_encoder` / `imu_odom` / `imu_store` | 姿态解算 / 编码器 / 里程计 / 零漂与航点存储 |
| `tof_ranging` / `tof_config.h` | TOF 测距驱动与配置 |
| `servo_control` / `test_config.h` | 舵机 PWM、脉宽↔角度换算、三点标定 |
| `menu_config.h` / `imu_config.h` | 引脚、按键、Flash 页、参数下标（改硬件只改这几个头） |

改了屏上的中文文案，记得重跑 `python tools/gen_font.py` 补字库（新字不在表里会显示成空白）。
