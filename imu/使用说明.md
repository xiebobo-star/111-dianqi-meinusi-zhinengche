# TC264 + IMU660RA 姿态解算 / 里程定位

工程位置：`D:\Infineon\AURIX-v1.10.40-workspace\imu`
底座是之前那个「多级菜单 + 参数掉电保存」工程（`menu`），这次在它上面加了陀螺仪和里程计。

---

## 1. 这次做了什么

| 功能 | 实现 |
|---|---|
| pitch / roll / yaw 姿态解算 | 互补滤波：陀螺积分 + 加速度计修正倾角（`imu_attitude.c`） |
| 菜单里实时看三个角 | 主菜单 →「姿态定位」→「姿态显示」，10Hz 刷新 |
| 姿态页看加速度 | `AccX/AccY`、`AccZ/a` 两行（仅 2 寸 IPS200），单位 g；平放静止应是 Z≈+1.00、a≈1.00 |
| 加速度的用途 | 互补滤波里用重力方向修正 pitch/roll；`a` 偏离 1g 太多时判为运动，静止零速修正（ZUPT）就不启动 |
| 零漂校准 + 存 Flash | 「陀螺校准」页按 3 自动采 1 秒算零漂，成功立刻写进 Flash 第 8/9 页；上电自动读回 |
| 编码器路程里程计 | 两路编码器（TIM4 / TIM5）10ms 采一次，累计脉冲 × 每脉冲毫米数（`imu_encoder.c`） |
| 相对初始位置的坐标 | 编码器路程 × 陀螺航向 做航迹推算，算出 X（前后）/ Y（左右），可随时把当前位置设为原点（`imu_odom.c`） |
| 间断记录路径 + 屏幕显示 | 每走 50mm 或车头转 10° 记一个轨迹点（环形缓冲 256 点）；「里程定位」页下半屏画小地图，「航点记录」页最多记 16 个位置点并自动存 Flash |

菜单结构（在原来三页的基础上）：

```
主菜单
 ├─ 姿态定位 ─ 姿态显示 / 陀螺校准 / 里程定位 / 航点记录   ← 本次新增
 ├─ 参数设置 ─ 电机参数 / 传感器参数 / 系统参数（原样）
 ├─ 状态查看 ─ 运行状态（多显示姿态、位置、里程）/ 存储状态 / 参数总览
 └─ 系统信息 ─ 版本 / 硬件（多显示 IMU、编码器）/ 操作说明
```

## 2. 接线（跟主板丝印对名字，不要按排针位置整块插）

| 接口 | 主板丝印 | TC264 引脚 | 备注 |
|---|---|---|---|
| IMU1 | SCL/SPC、SDA/MOSI、SDO/MISO、CS | P20_11、P20_14、P20_12、P20_13 | SPI0，逐飞库默认就是这个，不用改库 |
| 编码器1 | A/B | P02_8 / P00_9 | TIM4，方向解码模式 |
| 编码器2 | A/B | P10_3 / P10_1 | TIM5 |
| 屏幕1 | SCK/MOSI/CS/RST/DC/BLK | P15_3/P15_5/P15_2/P15_1/P15_0/P15_4 | SPI2 |
| 4 个按键 | — | P20_6 / P20_7 / P11_2 / P11_3 | 上 / 下 / 确定 / 返回 |

> IMU 模块一定要给 **3.3V**，接 5V 会烧。

## 3. 第一次用：按这个顺序点一遍

1. **上电** → 主菜单 →「姿态定位」→「姿态显示」，能看到 Roll / Pitch / Yaw 在动（第 4 行显示「静止 / 运动」和 `IMU OK`）。
   - 如果显示 `IMU ERR`：SPI0 的 4 根线没接好，或者模块没供电。
2. 把车**放在平地上、别碰它** → 进「陀螺校准」→ 按 **3**：屏幕先显示「采样中 请保持静止」，约 1~3 秒后显示「校准成功 已存Flash」。
   - 这一步算的就是零漂（车不动时陀螺仪也不该有读数，读到的那点就是零漂），成功会自动写进 Flash，以后上电直接用。
   - 失败会写原因：「校准失败 车在动」或「校准失败 零漂过大」。
3. 回到「姿态显示」，按 **1**（原点归零）：把当前这个位置和车头方向定义成 (0,0) 和 0°。
4. 推着车走一段（不用通电跑），进「里程定位」看 X / Y / 航向 / 总里程在变，下半屏会画出走过的绿色轨迹、黄点是航点、红点是当前位置。
5. 走到想记的位置，按 **3** 记一个航点（自动存 Flash），「航点记录」页能看到列表。
6. 想从新位置重新开始：任意页面按 **1**（原点归零）即可。

按键一览：

| 页面 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| 姿态显示 | 原点归零 | 清轨迹 | 去校准页 | 返回 |
| 陀螺校准 | 存 Flash | 零漂清零 | 开始校准 | 返回 |
| 里程定位 | 原点归零 | 清轨迹 | 记录航点 | 返回 |
| 航点记录 | 上选 | 下选 | 记录航点（长按 = 删除选中 / 清空全部） | 返回 |

## 4. 要改参数就改 `user/imu_config.h`（只改这一个文件）

| 宏 | 默认 | 说明 |
|---|---|---|
| `IMU_ATT_COMP_K` | 0.980 | 互补滤波系数，车抖就调大到 0.99，反应慢就调到 0.95 |
| `IMU_ATT_ZUPT_ENABLE` | 1 | 静止时锁住 yaw + 自动修零漂，**别关**（关了停着也会自己转） |
| `IMU_ATT_STILL_GYRO_DPS` | 1.5 | 判定「静止」的角速度阈值 |
| `IMU_ENC_PULSE_PER_ROUND` | 1024 | **车轮转一圈几个脉冲**，填错里程和坐标全不对 |
| `IMU_ENC_WHEEL_MM` | 61.0 | 车轮直径 mm，量一下 |
| `IMU_ENC_LEFT_INVERT` / `RIGHT` | 0 | 往前推车读数是负的 → 改成 1 |
| `IMU_ATT_GYRO_SIGN_Z` | 1 | 模块倒着贴（芯片朝下）时改成 -1 |
| `IMU_ODO_TRAIL_STEP_MM` | 50 | 每走多少 mm 记一个轨迹点（越小越细，但更占内存） |
| `IMU_ODO_WP_MAX` | 16 | 最多记几个航点 |

标定「每圈脉冲数」的小办法：车轮做记号，推车让轮子正好转 10 圈，把「里程定位」页的总里程 S 读出来，
`每圈脉冲数 ≈ 10 × π × 轮径 / (S / 现在的每圈脉冲数)`，改完重新烧一次再核一遍。

## 7. 已知限制（写报告时可以用）

- **yaw 会漂**：没有磁力计，yaw 只能靠陀螺积分。已经用「静止时锁住 + 自动修零漂」压住大部分漂移，但连续跑十几分钟仍会慢慢偏。
- **路程靠编码器**：轮子打滑、压到东西，里程会偏；上坡下坡也不影响 X/Y 平面坐标，但实际高度变化没算。
- **X/Y 依赖航向精度**：航向偏 5°，走 10 米横向就差约 0.9 米，所以校准零漂这一步不能省。
- 校准要在**平地 + 不动**的情况下做；1.8 寸 TFT180 屏幕高度不够，里程定位页只显示数字、不画小地图（逻辑自动判断）。
