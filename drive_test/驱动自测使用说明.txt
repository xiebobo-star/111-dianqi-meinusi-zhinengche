TC264 硬件驱动自测工程 使用说明
====================================

一句话：这是一个"插什么测什么"的工程。一个外设一个测试页，按键选、屏幕看，
        屏幕没点亮也不要紧，同样的结果会从调试串口(115200)打出来。

一、烧进去
    1. 打开 AURIX Development Studio
    2. File -> Import -> General -> Existing Projects into Workspace，
       选 D:\Infineon\AURIX-v1.10.40-workspace\drive_test
    3. 如果 Project Explorer 里没看到新文件：右键工程 -> Refresh（F5）刷一下
    4. Project -> Clean -> Build（Debug 配置），编译 0 error
    5. 点小虫子图标 Debug 下载（先把上一次的调试会话 Terminate 掉）
    6. 调试串口：波特率 115200 8N1，TX=P14_0 RX=P14_1

二、菜单怎么用
    按键1 = 上     按键2 = 下     按键3 = 确定     按键4 = 返回
    菜单里：1/2 上下选，3 进入
    测试页里：长按按键4 退出（普通按一下不算，防止测按键时误退出）

三、每个测试项怎么看结果
    LED灯    核心板两个灯交替闪 -> 正常
    按键     按哪个键，屏幕上那行就在 释放/短按/长按 之间变
    屏幕     整屏依次 红 绿 蓝 白 黑（颜色或花屏 = 屏型号选错/排线问题）
    串口     屏幕上"回环"数字在涨 = P14_0 和 P14_1 短接了；
             没短接就看电脑串口助手能不能看到文字，能看到就是发送正常
    电机     先把车轮架起来！1 加 2 减 3 换左右轮，短按4 停，长按4 退出
    舵机     1 加脉宽 2 减脉宽 3 回中，屏幕上显示脉宽 us 和角度
    编码器   手转车轮，左速/右速/累计 会变（速度单位 mm/s）
    拨码     拨 SWITCH1/2，屏幕上的 0/1 跟着变
    陀螺仪   初始化通过 + 静止时 Z 轴加速度 8000 左右（约 1g）
    摄像头   初始化通过后直接显示图像，右上角 FPS，正常 30~50 帧
    测距     手在测距头前面晃动，距离数值跟着变
    Flash    写入 0x1234ABCD，读回来一样 = 通过（这就是掉电保存的底层）
    全部自检 一次跑完 陀螺仪/摄像头/测距/Flash，屏幕上直接显示 通过/失败

四、开始测之前要改的 4 个地方（都在 user\dt_config.h）
    1. DT_DISPLAY_USE_IPS200   你手上是 2寸 IPS200 -> 保持 1（不用改）
    2. DT_MOTOR_MODE           PWM_DIR(0) = 一个脚PWM一个脚方向  /  DUAL_PWM(1) = 两个脚都PWM
    3. DT_IMU_TYPE             1 = IMU660RA   2 = ICM20602
    4. DT_TOF_TYPE             1 = DL1A        2 = DL1B
    其它引脚都是按"TC264主控板 V1.2"的丝印写的，跟你板子一样就不用动。

五、2寸 IPS200 这块屏要注意的
    - 型号码：8 个脚、带 BLK 的 SPI 版才是本工程用的 IPS200；
      13 个脚、带 INT/TX/RX 的是 IPS200PRO（中文串口屏），驱动函数完全不同，本工程不适用。
    - 供电：VCC 必须 3.3V，绝不能接 5V（屏是 3.3V 器件，接 5V 会烧）。
      主板屏幕那一排上写的是 VCC3V3，别插到只有 5V 的排针上。
    - 背光：BLK = P15_4，ips200_init() 里会把这一脚拉高。所以背光不亮 = 程序还没跑到初始化，
      或者只插了下载器没给主板供电（下载器带不动整板，5V 排针只有 3.1V、屏 VCC 会掉到 2.6V）。
      全黑先量：屏 VCC-GND 是不是 3.3V、主板 5V 是不是 5.0V。这两条不对就别改代码。
    - 屏幕内容是按 128 像素宽排版的，在 240 宽的 IPS200 上会自动左右居中，不用管。
      屏幕测试项会整屏填色（红绿蓝白黑），能整屏变色 = 数据线、背光、驱动都通了。
    - 如果你不是用原装短排线而是用杜邦线接的，60MHz 的 SPI 可能花屏/白屏：
      打开 libraries/zf_device/zf_device_ips200.h，把 IPS200_SPI_SPEED 从 60*1000*1000 改成 10*1000*1000。

六、电机驱动是「逐飞 DRV8701E 双电机驱动板」
    - 这块芯片是 PH/EN 接口：PWM 进 EN（调速），DIR 进 PH（高低电平定方向），
      每路电机只吃 2 根信号，所以 dt_config.h 里 DT_MOTOR_MODE 保持 PWM_DIR(0)，不用改。
    - 板上有一个横向拨动式【使能开关】：没拨到使能位置，两个电机都不会转，
      板载的「使能」指示灯也不会亮 —— 电机完全不动先看这个开关和这颗灯。
    - 供电 VM 6~26V（接电池），板上还有电源指示灯；板载隔离芯片，3.3V 信号直接接没问题。
    - PWM 最高 100kHz 以内都行，本工程用 17kHz，并且支持 100% 占空比。
    - 转反了：把 DT_MOTOR_INVERT_L / DT_MOTOR_INVERT_R 改成 1（不用拆线），
      或者把那个电机的两根线对调。
    - 菜单里选「电机」：按键1 每下 +10% 占空比，按键2 减，按键3 换左右轮，短按4 停，长按4 退出。
      测之前把车轮架起来。

七、注意
    - 测电机一定要把车架起来，或者把轮子悬空，防止窜出去。
    - 屏幕不亮先看串口：只要串口有 [xxx] 开头的日志，就说明程序在跑、驱动在调，
      问题只在屏幕那条链路（型号/供电/排线）。
    - 摄像头/测距/陀螺仪没插的时候，初始化会超时返回"失败"，不会卡死，直接退出就行。
    - 每进一个测试页都会重新初始化对应的外设，所以可以反复进出。

八、改了中文显示文案怎么办
    屏幕上的汉字是点阵字库（user\dt_cn_font.c），不是字体文件。
    改了 dt_test.c 里的中文，需要重新生成字库，否则新字显示成空白。
    让 Hermes 重新跑一遍字库生成脚本就行（跟这次一样），不要手写点阵。

九、按键换脚（记录：已经换回 P11_2）
    - 现在的按键脚：按键1=P20_6  按键2=P20_7  按键3=P11_2  按键4=P11_3（原板载设计，虚焊已补好）
    - 按键脚写在 libraries/zf_device/zf_device_key.h 的 KEY_LIST 上；用户板器件 dt_config.h 里的
      DT_KEY1_PIN ~ DT_KEY4_PIN 只是给「按键」页显示原始电平用的，必须和 KEY_LIST 保持一致。
    - 以后换脚：改 KEY_LIST + 改这 4 个宏 -> Project -> Clean... -> Build。
      一定要 Clean！增量编译不会因为头文件改了去重编 zf_device_key.c，会继续烧旧引脚（踩过这个坑）。
    - 「按键」页底部那行「电平 1111」是 4 个按键的原始电平（1=松开 0=按下），
      按下去数字不变就是线/焊点的问题，不是程序的问题。
