# BDS300 舵机独立测试工程

工程名：`TC264_Servo_BDS300`。

## 接线

PWM SIG=P33_9（ATOM1 CH1 / TOUT31，原 P21_6）；50 Hz（20 ms 周期）。舵机 VCC 使用 4.8–6 V 独立电源，推荐 5 V；TC264、舵机和电源 GND 必须共地。三针接口为 VCC、GND、SIG，不能从 TC264 的 IO 口给舵机供电。

所有模块共地，VCC 按实物模块标注。调试串口 UART0：TX=P14_0、RX=P14_1，115200 8N1。

## 菜单入口

本项目现已导入 `menu` 工程的应用层代码，入口为 `Application/cpu0_main.c`。菜单使用 1.8 寸 TFT180（SPI2，128×160）和 4 个按键，并把参数保存到 TC264 片内 DFlash 第 10/11 页。导入的菜单模块包括屏幕显示、中文点阵、按键消抖与长按、参数编辑、双页 Flash 保存、菜单状态机和 10 ms 定时中断。

菜单接线：屏幕 SPI2 使用 P15_3/P15_5/P15_2/P15_1/P15_0/P15_4；按键使用 P20_6、P20_7、P11_2、P11_3；板载 LED 使用 P20_9、P20_8；调试串口仍为 P14_0/P14_1。屏幕 VCC 接 3.3 V，按键按下为低电平，所有模块共地。具体操作见 [README_菜单工程说明.md](README_菜单工程说明.md)。

## 舵机说明

菜单的“参数设置 → Servo”里，`脉宽us`（500–2500 us，上电默认 **1540 us** = 中位 90°，为机械装不正做的软件补偿）和 `角度`（0.0–180.0°，默认 90.0°）是两个**可编辑、互相联动**的参数：改脉宽角度跟着变，改角度脉宽跟着变，另一边在修改时就会实时预览（按确定后正式写入）。编辑时短按 1/2 走一档（脉宽 10 us / 角度 1.0°），**长按 1/2 走一大步（脉宽 100 us / 角度 10.0°）并一直连发**；按键 3 确认、4 取消。角度是按 `Pulse min/center/max` 三个标定点（默认 **1040/1540/2040 us ↔ 0/90/180°**，每 90° 都是 500 us，斜率与原始标定一致）从脉宽换算出来的；舵机装到机构上对不齐时，只改 `Pulse center` 一项即可左右平移中位，三个点一起平移则比例不变，脉宽才是唯一真值。程序通过 P33_9（ATOM1 CH1 / TOUT31；原 P21_6）输出 50 Hz PWM，脉宽保护窗口和标定常量位于 `test_config.h`。运行状态页实时显示 脉宽 / 角度 / 占空比 / 输出开关。避免过载、供电不稳和接触不良，以免舵机发热或产生异常噪音。

## 导入与构建

ADS → File → Import → General → Existing Projects into Workspace，选择本目录；Debug → Build Project。目标为 TC26xD B-Step / tc26xb / bga292，沿用原工程。完整库、启动代码、链接脚本均在本目录，可以单独复制。应用入口为 `Application/cpu0_main.c`；每个工程只初始化自身部件与诊断串口。

底层逐飞通用库保留完整供应商版本和许可证；库中其他型号文件不表示该工程会初始化那些硬件。菜单应用层已复制到 `Application`，未复制原巡线、联合控制程序，也未复制旧 Debug 产物。

烧录时使用本工程本次构建的 ELF/HEX。编译检查结果见本目录 `VALIDATION.md`；实板尚未测试。

## 虚拟舵机测试

不接实体舵机时，可把 UART0 接到 USB-TTL，运行 [Virtual_BDS300/README.md](Virtual_BDS300/README.md) 中的虚拟 BDS300 监听器。主板按键和屏幕参数的操作保持不变；固件会输出 `BDS300 ... pulse_us=...` 遥测行，PC 端据此显示目标角度和 300 ms 模拟运动过程。
