# TC264 测距模块（VL53L1X）

> AURIX Development Studio 1.10.40 / 逐飞 TC264 开源库 / 工程：`Ranging Module`
> 传感器：**VL53L1X**（逐飞 DL1B 同芯片，量程约 **4 m**，16 位寄存器地址，IIC 地址 0x29）
> 接线：`VCC`=5V、`GND`、`SCL`=`P33_4`、`SDA`=`P33_5`、`XS`=`P20_10`（5 根线）
> 显示：IPS200（240×320）或 TFT180（128×160），在 `menu_config.h` 一行切换
> 本工程在「多级菜单 + 参数掉电保存」的基础上加了一个完整的测距模块：驱动封装、中值/平滑滤波、统计、报警、掉线判断、两个菜单页面

---

## 一、这个模块做了什么

| 功能 | 说明 |
|---|---|
| 测距 | VL53L1X 连续测量，约 30 帧/秒（由 TOF 自己的时序预算决定），单位 mm，量程 **4000 mm** |
| 车型适配 | `tof_config.h` 里 `TOF_SENSOR_TYPE` 默认 `TOF_SENSOR_DL1B`（强制按 VL53L1X 驱动，不读型号寄存器，上电最快）；换 L0X 改 `TOF_SENSOR_DL1A`；两块都想兼容改 `TOF_SENSOR_AUTO`（自动识别） |
| 滤波 | 三级可调：`0` 原始值 / `1` 中值滤波（5 点）/ `2` 中值 + 平滑（EMA 1/4），专治距离跳变和毛刺 |
| 有效性判断 | 按量程过滤：< 20 mm、> 4000 mm、`8190~8192` 这种「没读到」的哨兵值都算无效帧，不参与滤波/统计/报警 |
| 零点偏移 | 模块装在车壳里、比车头凹进去多少就填多少（mm），测出来的是「到车头」的距离 |
| 报警 | 距离 ≤ 阈值并连续 3 帧确认才报警，距离要大于「阈值 + 30 mm」才解除（回差），阈值附近不会一闪一闪 |
| 掉线判断 | 超过 250 ms 没有新帧 → 状态变「掉线」，距离显示 `--` |
| 统计 | 帧数 / 有效 / 无效 / 帧率 / 最小 / 最大 / 平均 / 波动，可一键清零 |
| 曲线 | 2 寸屏实时测距页下面画最近 64 个采样的面积图，黄线是报警阈值 |
| 屏幕自检 | 初始化失败时，实时测距页那个「--」框里直接显示 `C0=xx 10F=xx` 和 `SCAN n @0x29` —— 不用串口、不用示波器就能判断「线上没人应答」还是「芯片在、型号读不对」 |
| 参数掉电保存 | 报警距离 / 零点偏移 / 滤波等级 / 单位 / 报警开关都是菜单参数，写在 TC264 片内 Flash 第 10/11 页，断电不丢 |

## 二、接线（VL53L1X → TC264）

| 模块脚 | TC264 引脚 | 说明 |
|---|---|---|
| VCC | **5V** | 必须 5V；3.3V 会出现「近处能测、远处乱跳」，严重时初始化就失败 |
| GND | GND | 必须共地 |
| SCL | `P33_4` | 软件 IIC 时钟（引脚在 `libraries/zf_device/zf_device_dl1b.h` 里） |
| SDA | `P33_5` | 软件 IIC 数据 |
| XS（XSHUT） | `P20_10` | **必须接！** 初始化时拉低 10 ms 再拉高，让模块从干净状态重新启动；不接就可能第一次上电能测、MCU 一复位就起不来 |

**只接 5 根线**：VCC、GND、SCL、SDA、XS。

> 如果手上是 **VL53LXX-V2 那种 6 脚模块**（多一个 `GPIO1`）：`GPIO1` 默认不接；
> 想用中断读数就把 `GPIO1` 接到 `P14_3` 并把 `TOF_USE_INT` 改成 1。
> `P14_3` 在主板《尽量不要使用的引脚》清单里（boot 相关），所以默认不占用它。

屏幕 / 按键 / LED / 调试串口和原菜单工程一样：

| 功能 | 引脚 |
|---|---|
| 屏幕 SPI2 | SCK=`P15_3` MOSI=`P15_5` CS=`P15_2` RST=`P15_1` DC=`P15_0` BLK=`P15_4` |
| 按键 1/2/3/4 | `P20_6` / `P20_7` / `P11_2` / `P11_3` |
| 核心板 LED | `P20_9` / `P20_8` |
| 调试串口 | TX=`P14_0` RX=`P14_1` 115200 |

> 如果模块是插在主板的 IIC 座上，而那个座的脚不是 `P33_4/P33_5`，改
> `libraries/zf_device/zf_device_dl1b.h` 里的 `DL1B_SCL_PIN` / `DL1B_SDA_PIN` 两行
> （开了 `TOF_SENSOR_AUTO` 的话，`zf_device_dl1a.h` 里那两个也必须改成一样）。

## 三、型号 / 接线 / 采样方式的开关都在 `user/tof_config.h`

| 宏 | 默认 | 说明 |
|---|---|---|
| `TOF_MODULE_ENABLE` | `1` | 1 = 上电初始化测距模块；0 = 先不初始化（没接模块、只想调菜单时用，不碰 IIC、不报错） |
| `TOF_SENSOR_TYPE` | **`TOF_SENSOR_DL1B`** | 强制 VL53L1X（当前模块）。换 L0X 用 `TOF_SENSOR_DL1A`；要自动识别用 `TOF_SENSOR_AUTO` |
| `TOF_USE_INT` | `0` | 0 = 10 ms 轮询（默认，不接 GPIO1）；1 = 中断读数（GPIO1 接 `P14_3`） |
| `TOF_VALID_MIN_MM` | 20 | 小于它算无效 |
| `TOF_RANGE_L1X_MM` | **4000** | VL53L1X 量程（当前生效值） |
| `TOF_RANGE_L0X_MM` | 2000 | VL53L0X 量程（改成 DL1A / AUTO 时才用） |
| `TOF_FILTER_WINDOW` | 5 | 中值窗口，只能 3 或 5 |
| `TOF_TIMEOUT_MS` | 250 | 多久没数据算掉线 |
| `TOF_HOLD_MS` | 300 | 连续无效多久把显示值清成 `--` |
| `TOF_HISTORY_NUM` | 64 | 曲线存多少个点 |
| `TOF_INIT_RETRY` | 1 | 初始化失败重试次数 |
| `TOF_USE_MENU_PARAM` | 1 | 参数从菜单参数表来（0 = 用文件里的默认值） |
| `TOF_SERIAL_DEBUG` | 1 | 初始化 / 失败原因打到调试串口（UART0，115200） |

## 四、菜单怎么用

```
主菜单
 ├─ 测距模块
 │    ├─ 实时测距   ← 距离大数字 + 状态 + 帧率 + 量程条（4 m 满量程）+ 曲线（2 寸屏）
 │    └─ 测距统计   ← 型号 / 滤波 / 采样 / 帧率 / 有效 / 无效 / 最小 / 最大 / 平均 / 波动 / 阈值 / 状态 / 报警
 ├─ 参数设置（第 4 组「测距参数」）
 ├─ 状态查看
 └─ 系统信息
```

### 实时测距页按键

| 按键 | 作用 |
|---|---|
| 1 | 单位 mm ↔ cm 切换（改的就是「测距参数 → 单位cm」，会存 Flash） |
| 2 | 清统计（最小 / 最大 / 平均 / 曲线清零，报警不受影响） |
| 3 | 重新初始化模块（约 1 s，模块拔了再插上时用它救；改完线也可以按它，不用断电） |
| 4 | 返回上一级 |
| 长按 4 | 任何页面直接回主菜单 |

### 测距统计页按键

| 按键 | 作用 |
|---|---|
| 1 / 2 | 上翻 / 下翻（128×160 的小屏一屏 6 行，13 行要翻） |
| 3 | 清统计 |
| 4 | 返回 |

### 屏幕右上角的颜色

| 颜色 | 状态 | 意思 |
|---|---|---|
| 绿 | 正常 | 最近一帧有效 |
| 黄 | 弱信号 | 这一帧无效（太近 / 超量程 / 没回波），显示沿用上一次的有效值 |
| 红 | 掉线 | 250 ms 没有新帧：线掉了、模块没供电、选了中断方式却没接 GPIO1 |
| 蓝 | 待机 | 初始化成功，还没收到第一帧 |
| 灰 | 未初始化 | 初始化失败（模块没插好 / XS 没接 / 供电不是 5V）—— 这时大框会变成自检数据，见第八节 |

## 五、参数（参数设置 → 测距参数）

| 参数 | 默认 | 范围 | 步进 | 说明 |
|---|---|---|---|---|
| 报警距离 | 300 | 50 ~ 1500 mm | 10 mm | 小于等于它就报警（量程 4 m，但避障一般用不到 1.5 m 以上） |
| 零点偏移 | 0 | -500 ~ 500 mm | 1 mm | 模块比车头凹进去 20 mm 就填 -20 |
| 滤波等级 | 1 | 0 ~ 2 | 1 | 0 原始（最快最抖）/ 1 中值 / 2 中值+平滑（最稳最肉） |
| 单位cm | 关 | 关 / 开 | — | 开 = 屏上按 cm 显示（内部一律用 mm 算） |
| 报警开关 | 开 | 关 / 开 | — | 关 = 只测距，不报警 |

改完就生效（`tof_ranging.c` 每 10 ms 同步一次参数），退出修改界面自动存进 Flash，断电不丢。
**注意：参数项是 17 项，Flash 里旧格式的数据会因为「参数项数对不上」自动作废，上电就是默认值，重新改一遍保存即可。**

## 六、工程结构（新增文件都在 `user/`，库文件一行没改）

| 文件 | 作用 |
|---|---|
| `user/tof_config.h` | **测距模块的唯一配置文件**：型号、采样方式、量程、滤波、报警、曲线点数、串口日志 |
| `user/tof_ranging.c/.h` | 测距核心：芯片选型（DL1A/DL1B/AUTO）、驱动封装、有效性判断、零点偏移、中值/平滑滤波、统计、报警、掉线判断、曲线缓存、自检 |
| `user/menu_tof.c/.h` | 两个菜单页面（实时测距 / 测距统计），只调 `tof_module_*` 接口，不碰驱动 |
| `user/cpu0_main.c` | 上电流程：菜单初始化 → **TOF 初始化** → 上电延时 → 开 10 ms 中断 |
| `user/isr.c` | 10 ms 中断里多了 `tof_module_tick_10ms()` |
| `user/menu_config.h` | 5 个参数下标 `MENU_PARAM_IDX_TOF_*` |
| `user/menu_param.c/.h` | 参数表多了第 4 组 5 项；`MENU_PARAM_GROUP_NUM` 3→4、`MENU_PARAM_ITEM_MAX` 12→18 |
| `user/menu_ui.c` | 主菜单加「测距模块」、参数设置加「测距参数」、加 `MENU_UI_STATE_TOF` 状态与 10 Hz 局部刷新 |
| `user/menu_font.c` | 汉字点阵（已用 `tools/gen_font.py` 重新生成，229 个汉字） |

### 数据流

```
VL53L1X 测完一帧
  → 每 10 ms 轮询 dl1b_get_distance()（或 GPIO1 中断触发），数据进 dl1b_distance_mm、置 dl1b_finsh_flag
  → 10ms 中断 tof_module_tick_10ms()：计时、发现有新帧就取出 → tof_process()
  → tof_process()：判有效（20~4000 mm）→ 减零点偏移 → 中值/平滑滤波 → 统计 → 报警 → 曲线
  → 菜单页面（100ms 刷新）读 tof_module_distance_mm() / tof_module_state_str() 显示
```

中断里只有整数运算，没有 `printf`、没有浮点、没有延时；画屏和写 Flash 全在主循环。

## 七、给整车 / 避障用的接口（`tof_ranging.h`）

```c
tof_module_init();                      // 上电初始化一次（已经放在 cpu0_main.c 里）
tof_module_tick_10ms();                 // 10ms 中断里调（已经放在 isr.c 里）

uint16 mm    = tof_module_distance_mm();   // 滤波后的距离（mm），0 = 当前没有有效读数
uint8  ok    = (TOF_STATE_OK == tof_module_state());
uint8  near  = tof_module_alarm();         // 1 = 距离小于报警阈值（带确认 + 回差）
uint16 rate  = tof_module_rate_hz();       // 帧率，掉到 0 就是没数据了
uint16 rng   = tof_module_max_range_mm();  // 当前量程（VL53L1X = 4000）
const char *chip = tof_module_chip_str();  // "VL53L1X"
```

只想要「前面有没有障碍、多远」，三行就够：

```c
if ((0 != tof_module_alarm()) && (TOF_STATE_OK == tof_module_state()))
{
    // 前方 300mm 内有障碍：减速 / 停车 / 转向
}
```

`tof_module_reset_stats()` / `tof_module_reinit()` / `tof_module_set_alarm_mm()` 等见头文件注释。

## 八、初始化失败（屏上「未初始化」）怎么排查

屏右上角灰字「未初始化」= `tof_module_init()` 没成功，也就是**芯片没被配上**。
这时候那个本来是 `--` 的大框会显示自检数据，按「3」可以随时重新测一次：

```
+------------------------+
|   C0=FF 10F=EA         |   ← 型号寄存器原始值：10F=EA = 有 VL53L1X 应答；FF = 没人应答
|   SCAN 1  @0x29        |   ← IIC 总线上扫到几个器件，第一个在哪个地址（NO DEV = 一个都没有）
+------------------------+
```

| 屏上自检数据 | 意思 | 下一步 |
|---|---|---|
| `SCAN 0 NO DEV`（红字） | 总线上**一个器件都没应答** | 99% 是供电 / 接线 / XS，按下面「一表四步」量 |
| `SCAN 1 @0x29` + `10F=EA` | 芯片在线、确实是 VL53L1X | 芯片在线还失败 → **XS 没接好**（驱动复位不了它），或模块已被上一次的配置卡住：接好 XS，按 3 |
| `SCAN 1 @0x29` 但型号两个都 `FF` | 有器件应答、型号寄存器读不对 | 线太长 / 上拉不足 / 不是 VL53LXX 芯片；SCL/SDA 缩到 10 cm 内再试 |
| 一直是灰的、但串口说 init ok | 初始化成功只是没数据 | 看「掉线」那条：GPIO1 接了但 `TOF_USE_INT = 0` 不影响；主要查 XS 和 5V |

### 一表四步（只用万用表 DC 挡，模块端量，别在主板上量）

| 步骤 | 测哪 | 应该是 | 不对说明什么 |
|---|---|---|---|
| 1 | 模块 `VCC` 对 `GND` | **4.8 ~ 5.2 V** | 3.3 V 供电是最常见的坑：模块灯亮、IIC 不应答 |
| 2 | 模块 `GND` 对主板 `GND` | 通（≈0 Ω） | 不共地 = 没人应答 |
| 3 | 模块 `SCL` 对 `GND`、`SDA` 对 `GND`（空闲） | 都 **≈3.3 V** | 一根 0 V / 乱跳 → 接反，或接到了 `XS` / `GPIO1` 上 |
| 4 | 模块 `XS` 对 `GND` | ≈3.3 V | XS 悬空或没接，芯片可能一直处于关断；本工程 XS **必须**接 `P20_10` |

> 杜邦线一根一根按丝印对（别按颜色）。改完线在实时测距页按 **3** 重新初始化，屏上自检数据立刻刷新，不用断电。
> 有串口的话（`P14_0`=TX / `P14_1`=RX，115200）日志更细：`[tof] init VL53L1X ok ...` 或 `[tof] init FAILED ...` + `[tof] probe: ...`。

## 九、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 屏上「未初始化」 | 见第八节；先看大框里的 `SCAN / 10F` 两个数 |
| 上电初始化要等 1 秒左右 | VL53L1X 正常现象：`dl1b_init()` 要等模块固件启动（最长等 1000 ms），不是卡死 |
| 一直显示「掉线」 | 模块没数据：SCL/SDA 松了、XS 没接、模块没供电；或者 `TOF_USE_INT = 1` 但 GPIO1 线没接 |
| 距离一直是 `--`，状态「弱信号」 | 前面没东西（超过 4 m）、目标太黑/太亮/是玻璃、镜头上有膜 |
| 数值跳得厉害 | 把「滤波等级」改成 2；检查 5V 供电和共地；目标换白纸 / 纸箱 |
| 近了反而测不到 | TOF 盲区约 20~30 mm，贴脸检测要用微动开关/红外 |
| 想换成 VL53L0X 模块 | 把 `tof_config.h` 的 `TOF_SENSOR_TYPE` 改成 `TOF_SENSOR_DL1A`（量程自动变 2 m）；不确定型号就改 `TOF_SENSOR_AUTO` |
| 屏上汉字是空白 | 改过中文文案没重新生成字库：工程根目录跑 `python tools/gen_font.py` |
| 屏全黑 / 花屏 | 屏幕型号开关 `MENU_DISPLAY_USE_IPS200` 选错（IPS200 = 1，TFT180 = 0）；杜邦线太长把 SPI 降到 30 MHz |
| 参数改了不生效 | 参数页里按 3 进入修改、按 1/2 加减，退出修改才生效并存 Flash |
