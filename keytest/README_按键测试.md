# keytest —— 按键引脚测试工程

只有一个目的：**搞清楚板子上每个按键到底接在 TC264 的哪个脚**。
没有任何菜单逻辑、没有中断、没有 Flash，只有「读 12 个引脚电平 + 显示」。

## 怎么用

1. 上电（屏幕亮起来，第一行 `KEY PIN TEST`）。
2. 按板子上的**每个按键**，一个按 2~3 下，中间停一下。
3. 看屏幕：哪一行的电平从 `1` 变成 `0`、右边 `cnt` 加 1 → **这一行的引脚名就是这个按键真正的引脚**。
4. 屏幕没亮就看串口（`P14_0/P14_1`，115200）：会打

```
KEY P11_3 DOWN cnt=1
KEY P11_3 UP
```

## 屏幕长什么样

```
KEY PIN TEST
pin    L  cnt
P20_6  1    0
P20_7  1    0
P11_2  1    0      ← 按下去这一行会变红、L 变 0、cnt +1
P11_3  1    0
P20_5  1    0
P20_4  1    0
P11_9  1    0
P11_8  1    0
P33_11 1    0
P33_12 1    0
P02_5  1    0
P02_4  1    0
LAST:  P11_3       ← 最后按下的那个脚
```

- `L` = 电平（1 松开 / 0 按下，引脚都配了上拉）
- `cnt` = 这个脚累计被拉低几次
- 按下时整行变红，松手变白

## 测出来的结果怎么判断

| 现象 | 结论 |
|---|---|
| 按某个按键，**只有某一行**在 1/0 之间变 | 这个键就接在这一行的脚上，菜单工程里把对应 `MENU_KEY_PIN_xxx` 写成它即可 |
| 按某个按键，**一行都不动** | 这个按键本身/那根线有问题（没焊、按键坏、公共端没接 GND），跟程序无关 |
| **所有按键按下去都没反应** | 按键公共端（GND）没接，或者按键模块根本没插上；量一下按键一个脚对板子 GND 是否导通 |
| 某一行**一直是 0（一直红）** | 那个脚被外部拉死了（接到别的外设 / 短路），不是按键 |

## 说明

- 屏幕现在是 1.8 寸 TFT180（`cpu0_main.c` 顶部 `KEYTEST_USE_IPS200 = 0`；改回 1 就是 2 寸 IPS200）。
- TFT180 只有 128×160，12 个脚 + 标题 + 最后一行放不下 8×16 字，所以**用 6×8 小字体**（`TFT180_6X8_FONT`），字小但一屏能全看完；行高 17 起、每行 11 像素。
- 屏的 SPI 速度已经降到 10MHz（杜邦线用）。
- 测完这个工程就可以删掉，不影响 `menu` 工程。
